# @contadim/config

Configurações compartilhadas do monorepo.

| Export                                   | Uso                                     |
| ---------------------------------------- | --------------------------------------- |
| `@contadim/config/tsconfig/base.json`    | Base `strict` para todos os pacotes     |
| `@contadim/config/tsconfig/library.json` | Bibliotecas puras (`core`, `contracts`) |
| `@contadim/config/tsconfig/nest.json`    | API NestJS (decorators habilitados)     |
| `@contadim/config/tsconfig/react.json`   | Front-end React + Vite                  |
| `@contadim/config/eslint/node`           | ESLint para código Node.js              |
| `@contadim/config/eslint/react`          | ESLint para React                       |
| `@contadim/config/prettier`              | Prettier                                |
